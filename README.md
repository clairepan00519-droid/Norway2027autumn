## 第一次使用（家人同步）

和北海道版共用同一個 Supabase 專案，但資料存在另一張 `norway_sync` 資料表，兩個網站不會互相覆蓋；照片放在同一個 `trip-media` 空間的 `norway/` 資料夾。

1. 到 Supabase → **SQL Editor → New query**，貼上 `SUPABASE_SETUP.sql` 全部內容，按 **Run**（只要一次）。
2. 家人沿用北海道版的帳號登入即可。
3. 沒執行 SQL 前，登入後標頭會顯示「尚未建立 norway_sync 資料表」，資料先存在手機上，執行後會自動同步。

`config.js` 已填好與北海道版相同的網址與金鑰。之後更新網站時不要覆蓋這個檔案。兩個都留空＝單機預覽模式（不用登入，資料只存在這台裝置）。
